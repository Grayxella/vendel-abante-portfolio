VENDEL B. ABANTE — PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder "vendel_abante_portfolio".
3. Double-click index.html to preview the portfolio in your browser.

HOW TO EDIT
- index.html: text, sections, contact information.
- style.css: colors, spacing, layout, typography.
- script.js: mobile navigation behavior.
- assets/: the four supplied photos.

The website is responsive and uses a black-and-white editorial style.
An internet connection is needed for the optional Google Fonts. The site still works without them.

Before publishing publicly, confirm that the phone number, email address, and other personal details are okay to display.
